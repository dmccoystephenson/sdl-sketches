SDL Sketches

Three small programs written in C++ with SDL2 in January 2020, each from its own repository, compiled unchanged to WebAssembly with Emscripten. Pick one; each page links to the other two.

  • Controllable RectangleMove a black square around with the arrow keys, diagonals included. On a phone, on-screen arrows appear under it.
  • Rectangle Changing SizeGrow the square with the up arrow and shrink it with the down arrow, or with the Grow and Shrink buttons on a phone.
  • Bouncing RectangleA square bounces around the window, shifting colour each time it hits an edge. Nothing to press.

Sources: Controllable-Rectangle, Rectangle-Changing-Size, Bouncing-Rectangle-Using-SDL; browser build: dmccoystephenson/sdl-sketches.
